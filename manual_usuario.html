Manual de Usuario

Sistema Interactivo LiDAR • Consola de Calibración y Catálogo de Experiencias

Este manual describe el funcionamiento, puesta en marcha y uso del Sistema Interactivo LiDAR. La plataforma integra detección espacial en tiempo real mediante sensores LiDAR para transformar cualquier muro o pantalla en una superficie táctil e interactiva, ofreciendo tanto la Consola de Calibración Espacial como el Catálogo Multijuego de Experiencias 2D/3D y el juego tradicional de Gato LiDAR (Tres en Línea) con integración física de LEDs.

1. Inicio y Ejecución del Sistema

El sistema cuenta con un backend centralizado desarrollado en FastAPI y Python-SocketIO que procesa los datos del LiDAR en tiempo real y sirve tanto las APIs como las aplicaciones web en el puerto 8000.

1.1. Ejecución Manual (Consola / Terminal)

Comandos principales para iniciar el sistema:

cd /home/edgar-ld/Documentos/Proyectos/GatoLidar
source venv/bin/activate
python backend/app.py

1.2. Ejecución Automática con PM2 (Servicio en Segundo Plano)

Para instalaciones fijas o despliegue desatendido en la Raspberry Pi:

pm2 start ecosystem.config.json   # Iniciar el servicio
pm2 logs gato-lidar-backend        # Consultar logs en tiempo real
pm2 restart gato-lidar-backend     # Reiniciar servicio

3. Catálogo de Experiencias y Juegos Interactivos (/catalogo)

El Catálogo de Experiencias permite proyectar dinámicas visuales y sonoras sobre el muro que responden instantáneamente a los impactos de balones o toques físicos:

  • 🌊 Ondas Acuáticas (Fluid Waves): Simulación hidrodinámica con propagación de ondas físicas y síntesis de audio armónico reactivo.
  • 🌸 Particle Bloom: Generación procedural de flores y esporas que crecen a partir del punto exacto de contacto.
  • 🌌 Nebulosa Cósmica: Vórtices de partículas estelares aceleradas por fuerzas gravitatorias de atracción al tocar el muro.
  • 🌿 Jardín Vivo: Ecosistema botánico continuo con crecimiento de tallos y hojas que evoluciona con cada impacto.
  • ✨ Red de Partículas: Nodos elásticos interconectados que vibran y rebotan ante perturbaciones espaciales.
  • 🦅 Bandada de Pájaros (Boids): Simulación de bandadas en vuelo armónico que se dispersan ante los balones.
  • 👻 Nube de Sprites: Sistema de partículas y entidades con físicas de persecución y dispersión.
  • 🏰 Haunted Mansion (Cazafantasmas / Whac-A-Mole): Minijuego 2D con temporizador, niveles y objetivos móviles para golpear con el balón.
Consejo para Proyección: En la esquina superior del catálogo encontrará los botones para activar el modo de Pantalla Completa y alternar el visualizador de toques (Debug Pointer).

4. Consola de Calibración Espacial (/)

Permite adaptar el sistema a cualquier muro o pantalla física sin modificar código:

4.1. Parámetros del LiDAR

  • LiDAR X / Y: Distancia en metros desde el origen inferior izquierdo del muro hasta el sensor.
  • Rotación: Corrección angular para compensar desviaciones en el montaje físico del sensor.
  • Ángulos de Observación (Min / Max): Ventana angular de escaneo; todo rayo fuera de este rango se ignora para evitar ruidos de fondo.

4.2. Muro y Tablero Interactivo

  • Dimensiones de Muro: Ancho y alto físico en metros de la superficie de proyección.
  • Posición y Dimensiones de Tablero: Coordenadas (X, Y) y tamaño del área donde se delimitan las 9 casillas para el juego de Gato.
  • 📐 Ver Tablero: Casilla de verificación para mostrar u ocultar la cuadrícula sobre el canvas de calibración.

4.3. Filtros de Detección (Clustering DBSCAN)

  • Puntos Mínimos / Máximos: Cantidad de reflexiones del sensor necesarias para confirmar un balón (elimina ruido por polvo o reflejos débiles).
  • Radio Esperado y Distancia Máxima: Geometría del objeto agrupado para validar su centroide.
  • Cooldown Antirrebote: Milisegundos de espera tras un tiro para evitar que el rebote del balón registre un doble toque no deseado.

5. Juego de Gato LiDAR (Tres en Línea)

El juego de Gato se puede operar directamente desde la consola:

  • Modos de Juego: Jugador vs Jugador (PVP) o Jugador vs CPU (PVCPU).
  • Reglas Dinámicas: Límite de tiempo global, modo de robo de casillas y restricción de un solo intento por turno.
  • Luces Físicas y MQTT: Los eventos de casillas y turnos se publican automáticamente vía MQTT para controlar tiras LED o indicadores físicos enlazados al ESP32.

6. Resumen de Solución de Problemas

Situación Posible Causa Acción Recomendada
El LiDAR no detecta puntos Cable USB desconectado o puerto ocupado. Revisar conexión del puerto /dev/ttyUSB0 e iniciar de nuevo el backend.
Puntos fantasma fuera del muro Rango angular de observación demasiado amplio. Reducir los ángulos mínimo y máximo en el panel de calibración.
No hay sonido en el catálogo El navegador bloquea audio antes de interacción. Hacer clic en la pantalla para activar el audio y revisar la pestaña Audio de la consola.

7. Guía para Desarrolladores: Integración de Nuevos Juegos

Cualquier motor o interfaz externa (Web / Canvas, Three.js, Unity, Unreal Engine, Godot, TouchDesigner) puede conectarse al servidor mediante Socket.IO en http://<IP_HOST>:8000 para recibir eventos espaciales calibrados.

7.1. Eventos y Estructura de Datos (Payloads)

A. Evento lidar_cluster (Detección de Impactos de Balón u Objeto)

Es el evento primordial para videojuegos interactivos. Emite las coordenadas del centroide de impacto ya convertidas a metros respecto al origen inferior izquierdo del muro:

{
  "centroid": [1.452, 1.208],
  "points": 8,
  "radius": 0.095
}
  • centroid: Array [x, y] en metros respecto al muro.
  • points: Cantidad de reflexiones láser que conforman el impacto.
  • radius: Radio estimado del balón/objeto en metros.
  • null: Se emite cuando cesa el contacto sobre el muro.

B. Evento lidar_scan (Nube de Puntos Completa en Muro)

Emisión continua a ~15 Hz de los puntos válidos sobre el muro:

{
  "points": [
    { "x": 1.25, "y": 0.85 },
    { "x": 1.28, "y": 0.89 }
  ]
}
